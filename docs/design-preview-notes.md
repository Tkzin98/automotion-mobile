# Design preview notes

A referência aprovada segue quatro ideias:

- preto predominante e transparência curta;
- painel lateral direito sem moldura pesada;
- hierarquia: timestamp → categoria → informação principal → detalhe → linha de progressão;
- o conteúdo astronômico continua visível por trás do painel.

A V20 implementa essa estrutura como renderer, não como imagem estática.
