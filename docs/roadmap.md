# Roadmap técnico

## Agora — V20

- parser de `(0:08) texto`, SRT, VTT e JSON;
- planejamento automático por tipo de informação;
- quatro linguagens monocromáticas de documentação;
- posição horizontal fixa à direita;
- altura automática para reduzir colisão com o assunto;
- preview e render usando a mesma função de motion;
- áudio original preservado;
- nenhum efeito sonoro no código;
- documentação e testes de parser/planner.

## Próxima camada

- biblioteca de visuais por assunto;
- múltiplas cenas dentro do mesmo cue quando houver word timestamps;
- sistema de prioridade para escolher entre gráfico, diagrama e texto;
- análise de safe area baseada no frame;
- cache de assets e modelos locais;
- render incremental para dispositivos móveis;
- salvar/carregar projeto `.automotion.json`.
