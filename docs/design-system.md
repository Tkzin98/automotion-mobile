# Design system

## Referências pesquisadas

### NASA — display standards
A documentação de display da NASA recomenda posições relativas consistentes, agrupamento lógico e uso de sans serif; também recomenda fonte monoespaçada para números e dados tabulares. Isso orienta a hierarquia do AutoMotion: timestamp técnico pequeno, categoria discreta e informação principal em fonte proporcional. Fonte: https://www.nasa.gov/reference/appendix-f-vol-2/

### NASA — brand system
O guia digital atual da NASA usa Inter para hierarquia de interface e Public Sans para texto corrido, reforçando o uso de sans serif legível em telas. Fonte: https://www.nasa.gov/nasa-brand-center/brand-guidelines/

### NASA — visualization practice
A NASA também enfatiza consistência de estilo, legibilidade e redução de ruído visual em visualizações científicas. Fonte: https://www.nasa.gov/people-of-nasa/joshua-stevens-visualizing-nasas-world/

### Referência visual de interfaces espaciais
O projeto “Guide to the Expanse” no Behance mostra uma linguagem escura com órbitas finas, rótulos pequenos e muito espaço negativo. Fonte: https://www.behance.net/gallery/32285277/Guide-to-the-Expanse

## Regras do AutoMotion

1. O vídeo é o elemento dominante.
2. O sistema não usa painéis grandes como cartões de aplicativo.
3. O painel nasce como uma faixa de preto translúcido e uma linha vertical.
4. A posição horizontal é fixa na direita.
5. A altura pode ser automática para evitar áreas visualmente ocupadas.
6. Cor é reservada para significado; o padrão é monocromático.
7. Números e timestamps usam tratamento técnico/monoespaçado.
8. O motion entra dentro do timestamp do cue, nunca antes por cálculo aproximado.
9. Se uma frase não gera uma visualização explicável, nada é desenhado.
10. Efeitos sonoros não fazem parte da arquitetura.
