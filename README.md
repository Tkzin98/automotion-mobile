# AutoMotion Studio V18

Editor automático de motion design para vídeos documentais/astronômicos.

- Sem Whisper: a transcrição vem pronta e pode ser SRT, VTT, JSON ou `(0:08) texto`.
- Direção visual: preto, tipografia moderna, painel transparente discreto sempre à direita.
- Sound design removido: o áudio original é preservado sem efeitos adicionais.
- O motor escolhe automaticamente a visualização por tipo de informação.
- Render local em MP4 via Mediabunny + WebCodecs quando o navegador suportar.
